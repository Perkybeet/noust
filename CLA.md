## How to sign

Once, on Your first pull request, write this comment on it, word for word:

```text
I have read the CLA Document and I hereby sign the CLA
```

A check on the pull request asks for it and records Your GitHub account, the pull request and
the date in the `cla-signatures` branch of the repository, which anyone can read. The signature
covers every Contribution You send afterwards. The maintainer and the bots that update
dependencies do not sign.
